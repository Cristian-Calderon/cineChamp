  ⚠️ Nota Importante: API de TMDB

  El único componente que requiere configuración adicional es la API de TMDB:

  TMDB_API_KEY=tu_clave_aqui

  Para obtenerla:
  1. Ve a https://www.themoviedb.org/
  2. Crea una cuenta gratuita
  3. Settings → API → Request API Key
  4. Copia la clave en /server/.env

  Sin esta clave, los endpoints que consultan información de películas/series no funcionarán, pero toda la lógica de base de datos está 100% operativa.
